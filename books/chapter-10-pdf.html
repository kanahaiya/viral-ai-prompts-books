How to Use This Prompt Book

100 personalised historical time travel portrait image prompts — each with 6 variable slots. Replace the [TOKENS] with your details and paste into any AI image tool.
How to Use — 4 Steps
1
Each prompt contains 6 personal variables shown in [SQUARE BRACKETS] — such as [NAME] [ROLE] [PERIOD] etc. Replace each with your own details before using.
2
Browse the 100 prompts grouped into 5 categories. Find one that matches the look you want to create — each is a complete image generation prompt.
3
Copy the prompt text and replace every [TOKEN] with your personal detail. See the example below — it shows a blank template next to the same prompt fully filled in.
4
Paste the completed prompt into ChatGPT, Midjourney, Adobe Firefly, or DALL·E 3. The preamble at the top helps the AI understand each variable before it reads the creative prompt.
